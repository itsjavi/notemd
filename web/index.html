## Why

A simpler place for notes, prompts and plain text.

NoteMD started as a personal itch. Here is the short version, written the way it would be in the app.

# Why I built NoteMD

I wanted a simpler note-taking app: plain Markdown files, several separate vaults, and every change versioned with git without having to think about it.

I also kept rewriting the same AI prompts, so I added templates: put parameters in a note, fill in a form, copy the result. Voice notes and video reviews came next, because some thoughts are faster to say or show than to type.

And while I was at it, a proper editor for every other text file on my Mac. Goodbye, TextEdit.

  • Plain Markdown files, no lock-in
  • Multiple vaults, one window each
  • Automatic git history
  • Reusable prompt templates
  • Voice notes and video reviews
  • A text editor for everything else

Javi, author of NoteMD

## Features

Everything is a file. Every edit is kept.

Every edit, safely in git

Each vault is a git repository. NoteMD saves as you type and commits a few seconds after you stop, and again when you close the window, quit, or press ⌘S.

Version History shows what changed in each version, compares any of them with the current text, and restores one as a new commit. Deleted notes can come back too.

Reusable prompts, as forms

Add params to a note's front matter and write {{placeholders}}, with {{#if}}, {{#elseif}}, {{#unless}} and {{#each}} blocks. Conditions can compare values, like {{#if language == Swift}} or {{#if max >= 10}}. AI agents can write them too, with the create-reusable-prompt skill.

Use Template opens a form with ten field types (text, long text, number, toggle, choice, multiple choice, file, folder, date and list) and gives you the result to copy or save as a note. Made for the AI prompts you keep rewriting.

Voice notes, transcribed on your Mac

Record straight into a note. The clip is saved in the vault's assets/ folder and plays right in the preview.

Transcribe it with on-device speech recognition: the text is added under the clip as a quote, and the audio never leaves your Mac.

Video reviews and attachments

Drag or paste images, screen recordings and other files into a note. NoteMD copies them into assets/ or links them where they are, and audio and video play inline in the preview.

Keep time-stamped feedback next to the recording for quick design and code reviews. Attachments are stored with Git LFS, so history stays light.

Goodbye, TextEdit

Open any text file from Finder: .md, .txt, .env.example, code or config, whatever the extension. Markdown gets the editor and live preview, HTML a live preview of the page with its scripts and remote content blocked until you allow them, and everything else opens as plain text.

NoteMD shows up under Open With without taking over your default apps, and indents with tabs or spaces, as you prefer.

## Details

And the small things that add up.

  • Your files, your folders

    Any folder can be a vault. Open several at once, each in its own window, and switch between recent ones.

  • Folders, tags, search

    Give folders a color and an icon, tag notes in front matter, and search with tag:name or #name filters.

  • GitHub Flavored Markdown

    Tables, task lists, footnotes, alerts and autolinks, rendered by cmark-gfm, GitHub's own engine.

  • Editor, Split, Preview

    Write, read, or both side by side. Switch with ⌘1, ⌘2 and ⌘3.

  • Notes from anywhere

    Send text and files from other apps through the Services menu, the Dock icon, drag and drop, or paste.

  • Native and portable

    SwiftUI and AppKit, light and dark. No database, no proprietary format: just a folder and a git repository.

## Get it

Build NoteMD in a minute.

You need macOS 26 on Apple silicon, Xcode 26, git, and git-lfs for attachments. make install builds the release app and copies it to /Applications. 

git clone https://github.com/itsjavi/notemd.git
cd notemd
make install
